Sections and items

Each check is built from sections, such as cab, tyres and wheels, lights, trailer. Each section can have its own checklist. Add items that need a tick, a number (like mileage or tyre pressure) or a photo.

Different checks for different vehicles

Create as many templates as you need and assign them per vehicle. Drivers only ever see the one that fits.

Start from a sensible default

New companies get a default HGV style check with cab, lights and tyres, fluid leaks, body and load security, and a trailer section. Change it, or build your own from scratch.
