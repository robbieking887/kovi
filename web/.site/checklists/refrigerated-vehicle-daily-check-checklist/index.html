Refrigerated vehicle daily check checklist

A cold chain vehicle has to keep the load safe as well as keep the road safe.

Updated 1 November 2026 · 2 min read

Download the printable PDF

Home › Checklists › Refrigerated vehicle check

Vehicle

Use the normal daily check list or van list.

Refrigeration

  • Unit starts and runs, with no alarms
  • Set temperature correct for the load
  • Compartment at temperature before loading
  • Door seals undamaged and doors close fully
  • Fuel or power for the unit sufficient
  • Drain holes clear
  • Evaporator and air flow not blocked

Hygiene

  • Inside clean and dry, with no odours or residue
  • No damaged flooring or lining
  • Probes and data loggers working and calibrated as required

Record the temperature

In Kovi, add a number item for the temperature reading so each check has the figure recorded with time and driver.
