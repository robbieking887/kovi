6. Security measures

  • All traffic is encrypted in transit (HTTPS). Data is encrypted at rest by our hosting provider.
  • Passwords are stored only as salted bcrypt hashes. Driver PINs are stored only as keyed hashes and cannot be read back; they are shown once, when created.
  • Each customer's data is kept separate in software: a user can only reach their own company's records, and only office users (admins) can view photos and the full history. Drivers see only their own checks from the last 7 days.
  • Photos are kept in a private storage bucket that is not publicly accessible, and are only served to signed-in office users of the same company.
  • Limits on repeated sign-in attempts, and daily automated database backups.
  • Access to the production systems is limited to the people who run Kovi.
